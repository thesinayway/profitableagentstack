Scoring

How does Profitable Agent Stack score tools?

When a dated G2 rating is on file: value_score (0-100) = round(0.5 x fit + 0.3 x cost_score + 0.2 x sentiment_score). fit = editorial fit_score (1-5) x 20. cost_score = 100 - 60 x (entry_price - lowest entry price in the use case) / (highest - lowest); contact-sales tools get no cost or value score. sentiment_score = round(clip((Bayesian average - 3.0) / 2.0 x 100, 0, 100)), where Bayesian average = (50 x 4.3 + review_count x G2 rating) / (50 + review_count). Tools without review data are labeled "no review data yet" and keep value_score = round(0.625 x fit + 0.375 x cost_score). The category-wide value score uses the overall G2 rating. When segment ratings exist later, stack pages prefer the rating for that team size (solo/small -> small business, early/scaling -> mid-market, large -> enterprise). Stack picks also weigh fit for the GTM team size (reviewer company-size mix, case studies, enterprise-readiness evidence). Full method: https://profitableagentstack.com/methodology
