How can developers and AI agents use Profitable Agent Stack data?

Use the free, read-only JSON API at /api/v1 (OpenAPI at /openapi.json), the MCP server at /mcp, or the Markdown version of any page. No key needed. Prices last verified 2026-11-16.

Quickstart

No sign-up, no API key, no auth. CORS is open. Everything is read-only.

curl https://profitableagentstack.com/api/v1/stacks/small.json
curl "https://profitableagentstack.com/api/v1/tools.json?use_case=ai-sdr&max_price=100"
curl -H "Accept: text/markdown" https://profitableagentstack.com/stages/small-gtm-team

JSON API (v1)

EndpointWhat it returns
/api/v1/index.jsonEndpoints, team sizes, query parameters
/api/v1/tools.jsonAll 72 tools ranked by value: entry price, currency, price status, pricing source URL, last-verified date, fit, cost and value scores. Filters: use_case, team_size, max_price, q
/api/v1/tools/{tool_id}.jsonOne tool, e.g. /api/v1/tools/apollo.json
/api/v1/stacks.jsonRecommended stack for each GTM team size, line items, total, assumptions, skips, CRM pick
/api/v1/stacks/{team_size}.jsonsolo (1), small (2-5), early (6-15), scaling (16-40), large (40+)
/api/v1/use-cases.jsonUse cases with best-value and lowest-price tools
/api/v1/crm.jsonCRM pick and runner-up by team size (separate from stacks)
/api/v1/releases.jsonNew releases and price changes, with sources

OpenAPI 3.1 spec: /openapi.json. Errors are JSON problem details (RFC 9457) with code, detail and resolution. The original /api/tools.json stays available.

MCP server

A read-only Model Context Protocol server runs at https://profitableagentstack.com/mcp (Streamable HTTP, JSON responses, no auth). Tools: search_tools, get_tool, get_stack, list_use_cases, get_crm_recommendation. Add it to an MCP client as a remote server:

{"mcpServers": {"profitable-agent-stack": {"url": "https://profitableagentstack.com/mcp"}}}

Markdown and plain text

Every page has a Markdown twin at the same path ending in .md (for example /stages/small-gtm-team.md), linked from each page with rel="alternate" type="text/markdown". Requests with Accept: text/markdown get Markdown directly. Site summary: /llms.txt. Full text of every tool, stack and guide: /llms-full.txt.

Discovery files

  • /.well-known/api-catalog (RFC 9727 API catalog)
  • /.well-known/mcp/server-card.json (MCP server card, draft format)
  • /.well-known/security.txt (RFC 9116)
  • /sitemap.xml and /robots.txt (AI crawlers allowed)

How scores work

value_score (0-100) = round(0.625 x fit + 0.375 x cost_score). fit = editorial fit_score (1-5) x 20. cost_score = 100 - 60 x (entry_price - lowest entry price in the use case) / (highest - lowest); contact-sales tools get no cost or value score. The published formula reserves 20% for user sentiment, but no sentiment or user-review data is used in any score today, so fit and cost are reweighted 62.5/37.5. Stack picks also weigh fit for the GTM team size (reviewer company-size mix, case studies, enterprise-readiness evidence).
