- Source of truth: `tools.json`. Build: `python3 build.py` (no dependencies) → pre-rendered HTML, `api/tools.json`, `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt`.
- Fit scores are editorial; G2/Capterra ratings are null (sites blocked automated fetch) and only linked. Never add ratings without a source + date.
- Test: `python3 -m http.server 8000`. Articles: Markdown in `content/articles/*.md` (front matter: title, slug, date, summary; `{{tokens}}` filled by build.py) → /articles/. Affiliate links: set `affiliate_url` on a tool in tools.json only with a real, approved link; the build adds rel=sponsored, the "affiliate" badge and a page disclosure automatically. The Hebrew site is built from /workspace/pas-he and synced to ./il/ at the end of `python3 build.py` (gitignored). English pages must not link to /il/; robots.txt allows /il/ and lists https://profitableagentstack.com/il/sitemap.xml. Deploy: `/workspace/pas-ops/marketing/deploy_en.sh` (builds English+Hebrew, copies into /workspace/wr/dist including dist/il/, then `wrangler pages deploy`). A naive copy of this tree without running build.py will not include /il/.
- Brand (2026-11-11): assets/brand/ holds the D1 logo (pas-logo-dark.svg in header), favicon.svg/-32.png, apple-touch-icon.png, logo-512.png (Organization JSON-LD), og-default.png, and The Sinay Way logos (footer credit FCRED in build.py; navy logo on Advisory). Sources and generators: /workspace/pas-brand. The Sinay Way logo is intentionally not linked (thesinayway.com expired).
